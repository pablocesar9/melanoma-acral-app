# Imágenes de ejemplo de las pruebas

Cuatro imágenes dermatoscópicas públicas, de lesiones acrales, que usan las pruebas de captura de pantalla (`CapturasPantallasTest`). No son de pacientes de este trabajo.

Proceden del conjunto BALD (Müller et al., 2025, *The BRAAFF-Annotated Acral Lesions Dataset (BALD)*, Journal of Investigative Dermatology, 145, doi:10.1016/j.jid.2024.12.021), que las toma del ISIC Archive. Se copiaron tal como se distribuyen en BALD; solo se les cambió el nombre del archivo.
